# My Skills 🧠

A curated collection of custom skills, instructions, and prompt templates for AI assistants and daily learning workflows.

---

## 📌 Overview

This repository serves as a central hub for personal agent skills, system prompts, and formatting guidelines. Each skill defines clear triggers, execution steps, and structured output patterns to optimize interactions with AI assistants (such as Antigravity, Claude, ChatGPT, and Cursor).

---

## 📂 Available Skills

| Skill / Template | File | Description |
| :--- | :--- | :--- |
| **Notion Summary** | [`notion-summary.md`](./notion-summary.md) | Summarizes lecture slides, articles, or complex technical topics into high-density, Notion-ready study notes featuring bilingual (Thai-English) explanations, problem-solution logic chains, pro/con analyses, and comparison tables. |

---

## 🚀 How to Use

### 1. Direct Prompting
Copy the contents or specific rules from the skill markdown file (e.g., `notion-summary.md`) and paste them into your AI prompt along with the source material (lecture slides, notes, or articles).

### 2. Custom Instructions / Agent Setup
Integrate these skill definitions into your AI assistant workspace settings, agent instructions, or system prompt configurations to automatically invoke them whenever relevant keywords or tasks are mentioned.
